==================================================================

- mixed-conflicts
- incomplete-event-history
- competing-newer-states
- missing-sku

All runs were executed against the Docker warehouse APIs. Where a second run was
performed, the warehouse containers were kept running so the second execution
tested the state left by the first.

than being silently or repeatedly mutated.


FINAL RESULT
============

PASS

All four additional V3 scenarios behaved as intended against the Docker warehouse
APIs. Together with the earlier V3 manual results, the deterministic suite now
demonstrates successful reconciliation, selective investigation, shared repair
revisions, multi-conflict orchestration, and safe escalation for incomplete,
contradictory, or missing evidence.
